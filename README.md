# Landfall

A fantasy map generator you sketch with: draw coastlines on a blank sketchbook
world, raise mountains, plant forests, and watch time, climate, winds and
currents shape it.

Part of my design playground — see it live at
[portfolio.lakshmisrinath.com](https://portfolio.lakshmisrinath.com/) (Playground → Map).

## Run it

Single static page, no build step. Open `index.html`, or serve the folder:

```bash
python -m http.server 8000
# then open http://localhost:8000
```
